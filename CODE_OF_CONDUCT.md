# Code of Conduct

We are committed to a respectful, inclusive, and constructive community for everyone contributing to or using this project.

Examples of unacceptable behavior include harassment, discrimination, personal attacks, publishing private information, and disruptive or abusive communication.

Participants asked to stop unacceptable behavior are expected to do so. Maintainers may remove content or restrict participation when needed to protect the community. Report concerns privately to the repository maintainers rather than posting sensitive details publicly.
